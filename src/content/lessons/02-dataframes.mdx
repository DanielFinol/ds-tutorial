Almost every project starts with a table: rows are observations, columns are variables. In Python, the standard tool for tables is the **pandas DataFrame**. (Later we'll meet Polars, which has a very similar mental model.)

## Build a DataFrame

Usually you'd read a file with `pd.read_csv(...)` or `pd.read_parquet(...)`. Here we'll build a small dataset of coffee-shop orders in code. The first run also loads pandas, so it takes a moment.

<PyCell code={`
import pandas as pd

orders = pd.DataFrame({
    "order_id": range(1, 11),
    "store":    ["North", "South", "North", "East", "South", "North", "East", "East", "South", "North"],
    "drink":    ["Latte", "Espresso", "Latte", "Mocha", "Latte", "Mocha", "Espresso", "Latte", "Mocha", "Espresso"],
    "size_ml":  [350, 60, 470, 350, 350, 470, 60, 470, 350, 60],
    "price":    [4.20, 2.50, 4.90, 4.60, 4.20, 5.30, 2.50, 4.90, 4.60, 2.50],
})
orders.head()
`} />

## Inspect before you analyse

Always look at the **shape**, the **types** and a **summary** first. It's how you catch surprises early.

<PyCell code={`
print(orders.shape)
print(orders.dtypes)
orders.describe()
`} />

## Select and filter

Pick columns with a list of names, and filter rows with a boolean condition.

<PyCell code={`
big_drinks = orders[orders["size_ml"] >= 350]
big_drinks[["store", "drink", "price"]]
`} />

Combine conditions with `&` (and) and `|` (or). Wrap each condition in parentheses.

<PyCell code={`
orders[(orders["store"] == "North") & (orders["price"] > 4)]
`} />

## Group and aggregate

"Split, apply, combine" answers questions like *"what's the revenue per store?"*

<PyCell code={`
summary = (
    orders.groupby("store")
          .agg(orders=("order_id", "count"), revenue=("price", "sum"), avg_price=("price", "mean"))
          .sort_values("revenue", ascending=False)
)
summary
`} />
