**Exploratory data analysis (EDA)** is where you build intuition: what do values look like, what's missing, what relates to what? Plots are the fastest way to see it.

## A synthetic dataset

We'll simulate 300 apartments where rent depends on size plus noise, so we know the "truth" and can check what the plots tell us.

<PyCell code={`
import numpy as np
import pandas as pd

rng = np.random.default_rng(seed=42)
n = 300
size_m2 = rng.normal(70, 20, n).clip(25, 160)
distance_km = rng.exponential(5, n)
rent = 300 + 14 * size_m2 - 25 * distance_km + rng.normal(0, 120, n)

flats = pd.DataFrame({"size_m2": size_m2.round(1), "distance_km": distance_km.round(2), "rent": rent.round(0)})
flats.describe().round(1)
`} />

## Distributions

A histogram shows the shape of one variable: its centre, spread, skew and outliers.

<PyCell code={`
import matplotlib.pyplot as plt

fig, axes = plt.subplots(1, 2, figsize=(9, 3.2))
axes[0].hist(flats["size_m2"], bins=25, color="#1f6f5c")
axes[0].set(title="Size (m²)", xlabel="m²", ylabel="count")
axes[1].hist(flats["distance_km"], bins=25, color="#c26a2e")
axes[1].set(title="Distance to centre (km)", xlabel="km")
fig.tight_layout()
`} />

Notice that size is roughly symmetric, while distance is **right-skewed**: most flats are close, a few are far away. Skew matters when choosing summaries (median vs. mean) and models.

## Relationships

A scatter plot shows how two variables move together.

<PyCell code={`
fig, ax = plt.subplots(figsize=(6, 4))
ax.scatter(flats["size_m2"], flats["rent"], s=12, alpha=0.6, color="#1f6f5c")
ax.set(xlabel="Size (m²)", ylabel="Monthly rent", title="Bigger flats cost more")
`} />

## Correlation

The correlation matrix condenses pairwise linear relationships into numbers between -1 and 1.

<PyCell code={`
flats.corr().round(2)
`} />

> Correlation is **not** causation, and it only captures *linear* association. Always look at the plot too: very different datasets can share the same correlation.
